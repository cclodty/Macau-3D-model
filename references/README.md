# 八達新邨及慕拉士馬路參考素材庫

本目錄集中管理八達新邨、慕拉士馬路及澳門街道元素的建模參考。原始相片、下載底圖或量度結果加入版本庫前，必須先在 [`catalog.csv`](catalog.csv) 登記；檔名使用 `YYYYMMDD_地點_主題_方向_序號.ext`，不使用人名或其他個人資料。

## 分類

| 目錄 | 收集範圍 |
| --- | --- |
| [`maps/`](maps/) | 公開地圖、航拍底圖、控制點及來源說明 |
| [`street_photos/`](street_photos/) | 八達新邨各座正面、側面、裙樓、天台輪廓，以及慕拉士馬路雙向道路、行人路、路緣、過路設施和車道標記 |
| [`facades/`](facades/) | 大廈入口、商舖門面、鐵閘、簷篷及柱位 |
| [`signage/`](signage/) | 店舖招牌、交通牌及其他文字或導向標誌 |
| [`street_furniture/`](street_furniture/) | 街燈、欄杆、消防栓、電箱、垃圾桶及巴士設施 |
| [`materials/`](materials/) | 外牆磁磚、混凝土、金屬、玻璃、路面及行人路鋪裝的正面材質相片 |
| [`measurements/`](measurements/) | 現場量度、已知標準尺寸、校準計算及可信程度 |

各子目錄的 `README.md` 列出拍攝要求；實際素材尚待具備現場拍攝權限的人員收集。不要以網上圖片搜尋結果或街景截圖代替已確認授權的原檔。

## 每項素材的必要記錄

`catalog.csv` 每列對應一個檔案或一項現場觀察，至少填寫：

* `id`、相對 `file_path`、分類及簡短用途；
* 拍攝方向（方位角或八方位；不適用時寫 `N/A`）；
* 約略位置（街道／路口／大廈座號；為保障私隱，不記錄私人單位或可識別個人的精確位置）；
* 拍攝或擷取日期；未知日期不得猜測，寫 `unknown`；
* 作者／來源 URL、授權狀況與授權證據位置；
* 私隱檢查結果及任何模糊／裁切處理；
* 尺寸可信程度和判斷依據（如適用）。

日期一律採用 `YYYY-MM-DD`。方位以相機朝向為準；例如站在道路南側向北拍攝便記 `N`，雙向道路應分開記錄兩個行車方向。約略位置應足以讓團隊重訪，但不得指向私人空間。

## 私隱與收錄規則

1. 整理時放大檢查人臉、車牌、門禁資料、信箱姓名、室內及窗戶反射。
2. 優先排除涉及私人空間或沒有建模用途的畫面。確有必要保留時，先在工作副本不可逆地模糊或裁走人臉和車牌，再加入本目錄；不得提交未處理原圖。
3. 在 `privacy_status` 記錄 `clear`、`blurred`、`cropped` 或 `excluded`。標記為 `pending` 或 `excluded` 的檔案不得提交。
4. 不收錄可識別路人、車主、住戶或店員的文字描述。公開場合拍攝仍須遵守現場告示及適用法律。

## 尺寸校準與不確定性

建模尺寸須在 [`measurements/measurement_log.csv`](measurements/measurement_log.csv) 留下可追溯依據，並盡可能用以下至少兩種獨立來源交叉校準：

1. 公開地圖或有明確比例尺／座標系的航拍底圖；
2. 現場使用卷尺、雷射測距儀或測量儀器所得數據；
3. 有正式出處及版本的已知標準尺寸；
4. 相片中與目標處於相近平面的可靠尺度物。

不得從有透視變形的單張相片直接宣稱精確尺寸，也不得把地圖螢幕截圖的像素距離當作測量值。記錄使用的工具、單位、原始讀數、校準來源及計算方式；保留原始值，不只保留四捨五入結果。

可信程度只使用以下級別：

| 級別 | 定義 | 模型使用方式 |
| --- | --- | --- |
| `high` | 現場量度或具比例／座標的權威資料，且由另一獨立來源核對 | 可作主要尺寸，仍須保留容差 |
| `medium` | 一個可靠量度來源，或多個彼此吻合的間接來源 | 可建模，但應預留修訂空間 |
| `low` | 單張相片、粗略地圖或未確認標準推算 | 只作暫定比例，必須清楚標示 |
| `unknown` | 無足夠依據 | 不建立數值尺寸，等待補測 |

所有不能確認的高度、闊度或距離必須標成 `low` 或 `unknown`，並在 `notes` 寫明假設；禁止把估算值改寫成精確測量。`measurement_log.csv` 的 `value_type` 必須明確區分 `measured`、`standard`、`derived` 和 `estimate`。

## 來源與授權登記

目前未收入第三方地圖、航拍圖或相片，因此沒有可轉授權的素材。每次新增前應：

* 優先使用作者自攝、政府開放資料或授權條款清楚的原始來源；
* 閱讀來源在下載當日的條款，將來源頁、作者、授權名稱／版本、必要署名及下載日期寫入 `catalog.csv`；
* 將授權頁或書面許可的存檔位置記入 `license_evidence`；只有「可觀看」而沒有重用許可的內容只可列為外部線索，不得複製入庫；
* 對地圖及航拍圖另記比例尺、座標參考系、資料日期及供應者；來源日期與下載日期不可混為一談；
* 授權不明時把 `license_status` 設為 `unverified`，且不要提交素材檔案。

## 基準日期

希望重現的基準日期目前為 **待項目負責人確認**。在確認前，模型不得把不同年份的招牌、路面配置或外牆狀況拼成同一個「精確」時點。暫以每項素材自身的 `capture_date` 管理時間，並在 `baseline_relevance` 標記 `candidate`、`matches`、`before`、`after` 或 `unknown`；基準日期確認後再統一篩選。此文件最後整理日期為 **2026-09-07**，並非場景基準日期。

## 建議工作流程

1. 先在地圖標出大廈各座、道路兩側及路口的拍攝點，避免只拍到單一立面。
2. 現場先拍環境定位照，再拍正面且盡量與表面平行的細節照；材質照避免強烈陰影、反光及透視。
3. 尺度照放置合法、安全且尺寸已核實的尺度物；不可妨礙道路或進入私人地方。
4. 匯入前完成私隱及授權檢查，使用不含個人資料的檔名，填妥 `catalog.csv`。
5. 對關鍵高度、道路闊度和柱距進行第二來源核對，在量度紀錄中保留差異、容差及可信程度。
